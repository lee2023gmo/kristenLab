# KristenLab

KristenLab 是一个基于 Qt Widgets 和 C++17 的 2D 重力解谜游戏。玩家通过切换重力方向，引导角色穿过墙体、死亡区、缓冲区、数据碎片、蹦床和激光门，到达终点。

## 功能概览

- 关卡从 JSON 文件加载，支持内置关卡和自定义关卡。
- 支持主菜单、关卡选择、暂停、重开、上一关 / 下一关。
- 支持游戏内编辑模式，只允许修改设计师指定的候选点。
- 内置关卡设计器，可绘制地图元素、候选点，并保存或导入 JSON。
- 支持大地图缩放、滚动条和 150×150 关卡编辑。
- 支持缓冲区、数据碎片、激光门、六种蹦床等机关。

## 运行方式

项目使用 CMake 构建，依赖 Qt Widgets 模块。

```bash
cmake -S . -B build
cmake --build build
```

也可以直接用 Qt Creator 打开 `CMakeLists.txt`，选择合适的 Qt Kit 后构建运行。

## 操作说明

| 操作 | 功能 |
|---|---|
| 方向键 | 改变重力方向 / 贴墙移动 |
| R | 重开当前关 |
| Space | 暂停或继续 |
| P | 上一关 |
| N | 下一关 |

## 地图元素

| 字符 | 含义 |
|---|---|
| `0` | 空地 |
| `1` | 墙体 |
| `2` | 起点 |
| `3` | 终点 |
| `4` | 死亡区 |
| `5` | 旧版弹射块，保留兼容 |
| `6` | 缓冲区 |
| `7` | 旧版传送带，保留兼容 |
| `8` | 数据碎片 |
| `L` | 激光门 |
| `9` | 蹦床，右上 |
| `u` | 蹦床，左上 |
| `v` | 蹦床，右下 |
| `w` | 蹦床，左下 |
| `r` | 蹦床，向右 |
| `l` | 蹦床，向左 |

## 关卡 JSON 格式

```json
{
  "name": "关卡名",
  "targetReverseCount": 6,
  "map": [
    "111111",
    "120031",
    "111111"
  ],
  "editablePoints": [
    { "row": 1, "col": 2 }
  ]
}
```

字段说明：

- `name`：关卡名称。
- `targetReverseCount`：推荐或目标反转次数。
- `map`：等宽字符串数组，每个字符代表一个地图元素。
- `editablePoints`：玩家编辑模式允许修改的位置，可为空。

## 目录结构

```text
.
├── levels/                 # 内置关卡
├── custom_levels/          # 自定义关卡
├── resources/images/       # 图片和 GIF 资源
├── docs/                   # 精简后的项目说明
├── gamescene.*             # 游戏主循环、碰撞、机关、绘制
├── leveleditordialog.*     # 关卡设计器
├── levelmanager.*          # 关卡加载、校验、保存
├── mainwindow.*            # 主菜单、关卡选择、游戏窗口
├── tiledefs.h              # 地图元素定义
└── CMakeLists.txt
```

## 开发备注

旧版 `5` 弹射块和 `7` 传送带仍在引擎中保留兼容，但设计器主要推荐使用缓冲区、激光门和蹦床。更多演进记录见 `docs/CHANGELOG_SUMMARY.md`。
