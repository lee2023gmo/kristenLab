# 变更记录摘要

本文件合并了原项目中分散的阶段性 README，保留对维护有价值的信息，删除重复的“阶段 N / 修正版”说明。

## 主要功能演进

1. 基础游戏框架：Qt Widgets 窗口、场景、计时器和角色移动。
2. 关卡系统：从 `levels` 和 `custom_levels` 加载 JSON 关卡。
3. 菜单系统：主菜单、关卡选择、帮助说明和游戏窗口切换。
4. 关卡设计器：表格化地图绘制、元素选择、校验、导入和保存。
5. 玩家编辑模式：设计师可指定候选点，玩家只能修改这些位置。
6. 机关扩展：缓冲区、数据碎片、蹦床、水平蹦床、激光门。
7. 碰撞优化：修复贴墙移动、平台边缘、内凹角、侧墙卡住等问题。
8. 大地图支持：缩放、滚动条、窗口自适应和 150×150 地图上限。

## 当前设计约定

- 上下墙是可操作支撑面；左右墙只作为阻挡，不提供吸附。
- 水平移动时允许继续接触当前支撑面，避免方形碰撞体被地面或天花板误判为阻挡。
- 竖直坠落贴到侧墙时允许忽略对应侧边，避免斜向蹦床弹射后卡在墙边。
- 水平蹦床需要角色到达格子中心后再触发，减少墙角卡死。
- 激光门亮起时视为阻挡，熄灭时可通行；角色如果停在激光格内，亮起时会被弹回最近安全位置。
